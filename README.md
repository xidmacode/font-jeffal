# JËFAL Frontend

JËFAL est une application web destinée à simplifier la gestion d'une activité économique.

## Description

L'application permet notamment de gérer :

- les produits ;
- les ventes ;
- les dépenses ;
- les dettes ;
- l'activité de l'entreprise ;
- les informations de l'entreprise ;
- le tableau de bord ;
- les interactions vocales.

Le frontend est développé avec React, TypeScript et Vite.

## Technologies

- React
- TypeScript
- Vite
- React Router
- CSS
- API REST du backend JËFAL
